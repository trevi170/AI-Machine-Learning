Part 13 – Simple Classification Program

Classification means placing something into a category.

score = 88

if score >= 70:
    classification = "Pass"
else:
    classification = "Fail"

print("Score:", score)
print("Classification:", classification)

This is not machine learning yet. We created the rule ourselves.
