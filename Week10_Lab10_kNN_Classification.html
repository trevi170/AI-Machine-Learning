Task 1 — Create the dataset (2 points)

Copy the code into a Code cell and run it.

import pandas as pd

df = pd.DataFrame({

Task 2 — Choose features and split the data (3 points)

Run the following code. Double brackets keep X as a two-column table. test_size=0.25 reserves 25% of the rows for testing; random_state=42 makes the split repeatable; stratify=y preserves class proportions.

from sklearn.model_selection import train_test_split

X = df[["Hours_Studied", "Practice_Quizzes"]]
y = df["Passed"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
print("Training rows:", len(X_train))
print("Testing rows:", len(X_test))

Expected: Training rows: 15 and Testing rows: 5.

Written questions (Text cell): Q3. What does X contain? Q4. Why should the test rows be kept separate from the training rows?

Task 3 — Train a kNN model (3 points)

Import the classifier, set k to 3, and train it using the training rows.

from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)
print("Model trained successfully")

Expected: Model trained successfully. k=3 means the algorithm checks three nearest training examples to vote on a class.

Written questions (Text cell): Q5. In your own words, what does k=3 mean? Q6. Why do we use X_train and y_train in fit()?

Task 4 — Test the model (3 points)

Run the predictions and calculate accuracy. The confusion matrix summarizes correct and incorrect predictions by class.

from sklearn.metrics import accuracy_score, confusion_matrix

predictions = model.predict(X_test)
print("Actual:", y_test.to_list())
print("Predicted:", predictions.tolist())
print("Accuracy:", accuracy_score(y_test, predictions))
print("Confusion matrix:")
print(confusion_matrix(y_test, predictions))

Expected for this fixed example: Actual: [0, 0, 1, 1, 1]; Predicted: [0, 0, 1, 1, 1]; Accuracy: 1.0; confusion matrix [[2,0],[0,3]]. The small artificial dataset is unusually easy; perfect accuracy here does not guarantee future accuracy.

Written questions (Text cell): Q7. What does an accuracy of 1.0 mean on these five test rows? Q8. How many test examples were predicted correctly?

Task 6 — Compare different k values (2 points)

Run the loop. It creates a fresh classifier for each value of k. Compare their results.

for k in [1, 3, 5]:
    candidate = KNeighborsClassifier(n_neighbors=k)
    candidate.fit(X_train, y_train)
    score = accuracy_score(y_test, candidate.predict(X_test))
    print("k =", k, "accuracy =", round(score, 2))

Expected: three lines, one each for k = 1, 3, and 5.
