Part 2 – Machine Learning Vocabulary

Machine learning uses data examples to discover patterns that can be used for predictions or grouping. In supervised learning, the training examples include the answer we want the model to learn. In unsupervised learning, the data does not include a target answer and the algorithm looks for patterns or groups.

Part 5 – Features and Labels

A feature is input information used to make a prediction. A label or target is the answer the supervised model is supposed to learn to predict.

For this example, imagine that we want to predict whether a student will pass. We will use Hours Studied, Attendance, and Previous Score as features. Passed will be the target.

X = df[["Hours_Studied", "Attendance", "Previous_Score"]]
y = df["Passed"]

print("FEATURES (X)")
print(X)

print()
print("TARGET (y)")
print(y)
