Task 4: Scale the features

Practice questions are larger numbers than hours; scaling prevents the larger numeric scale from automatically dominating distance.

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
print(X_scaled.round(2))

What this code does: fit_transform learns each feature’s mean and standard deviation and standardizes the data.

🧠 THINK 4: Why is scaling useful when k-Means measures distance?

Task 5: Train k-Means with two clusters

Choose k=2 because this introductory exercise asks for two groups.

model = KMeans(n_clusters=2, random_state=42, n_init=10)
df["Cluster"] = model.fit_predict(X_scaled)
print(df)

What this code does: n_clusters=2 requests two groups; fit_predict fits the model and returns a cluster number for each row; random_state makes results reproducible.

Task 6: Count students in each cluster

Count the members assigned to each group.

print(df["Cluster"].value_counts().sort_index())

What this code does: value_counts() counts each cluster label; sort_index() sorts labels numerically.

Task 7: Inspect cluster centers

Convert cluster centers from standardized units back into original units.

centers = scaler.inverse_transform(model.cluster_centers_)
print(pd.DataFrame(centers, columns=X.columns).round(2))

What this code does: cluster_centers_ stores average positions in standardized units; inverse_transform returns them to hours and question counts.
