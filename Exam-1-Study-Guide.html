type() reports a value's data type. input() returns a string by default. Use int() to convert appropriate text to a whole number and float() for a decimal number.

age = int(input("Enter age: "))
price = float(input("Enter price: "))
Important: 25 is an integer; "25" is a string. Correct data types matter because they determine how Python can process a value.
score = 80
score = 90
print(score)

The final value is 90 because the newer assignment replaces the old value.

score = 84

    print("A")

    print("B")

    print("C or below")

Output: B.

Week 4 – Loops and Functions

Loop: repeats instructions. This is useful for processing many values in a dataset.
for number in range(5):
    print(number)

Output: 0, 1, 2, 3, 4. The ending value 5 is not included.

for number in range(1, 6):
    print(number)

Output: 1, 2, 3, 4, 5.

A function is a reusable block of code and begins with def. A parameter receives a value supplied when the function is called. return sends a result back to the caller.

def double(number):
    return number * 2

print(double(4))

Output: 8.

Functions make code reusable and reduce duplication. A loop plus an if statement can process many scores and classify each one as Pass or Fail.

Week 5 – pandas and DataFrames

pandas is a Python library for organizing, inspecting, analyzing, and preparing structured data. The standard import is:

import pandas as pd
DataFrame: a table-like data structure. A row typically represents one observation/record. A column represents one attribute or type of information.

.mean()Average

df["Passed"] = df["Exam_Score"] >= 70

This creates Boolean True/False values based on whether each score is at least 70.

A CSV file is commonly used to store tabular data. df.to_csv(...) saves data and pd.read_csv(...) loads it.

pandas matters for machine learning because models need organized data. pandas helps inspect, summarize, clean, and prepare that data.
