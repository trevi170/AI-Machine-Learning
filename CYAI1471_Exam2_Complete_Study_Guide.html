Week 6 – Machine Learning Foundations

Core ideas

Machine learning (ML) uses examples in data to learn patterns. Those patterns can be used to make predictions or discover groups. In traditional rule-based programming, a person explicitly writes the rules.

ConceptKnow this
Supervised learningTraining examples include known targets or labels.
Unsupervised learningExamples have no target labels; algorithms can find groups or patterns.
ClassificationPredict a category such as Pass/Fail or Spam/Not Spam.
RegressionPredict a numerical value such as exam score or house price.
ClusteringGroup similar observations without known group labels.
FeatureInput variable used to make a prediction.
Target/labelAnswer a supervised model is trained to predict.
ObservationOne example, often represented by a row.

DataFrames, X, and y

import pandas as pd

df = pd.DataFrame({
    "Hours_Studied": [2, 4, 6],
    "Attendance": [70, 85, 95],
    "Passed": ["No", "Yes", "Yes"]
})

X = df[["Hours_Studied", "Attendance"]]
y = df["Passed"]
print(X.shape)
print(y.shape)

Output: (3, 2) and (3,). There are three observations, two feature columns, and one target value for each observation.

Remember: X and y are conventional variable names, not Python keywords. An ID column is not automatically a useful feature.

Read and predict the code

import pandas as pd
import numpy as np

df = pd.DataFrame({"Hours": [2, 4, np.nan, 6],
                   "Method": ["online", "Online", "GROUP", "group"]})
print(df.isna().sum())
df["Hours"] = df["Hours"].fillna(df["Hours"].mean())
df["Method"] = df["Method"].str.title()
print(df["Hours"].tolist())
print(df["Method"].unique())

Expected: one missing value in Hours, zero in Method. The Hours mean is 4, so the filled list is [2.0, 4.0, 4.0, 6.0]. The categories become Online and Group.

from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(

Important: If data-cleaning statistics such as means are learned from the data, in a real modeling workflow they should be learned from training data and then applied to test data. This helps avoid leakage. Small classroom datasets are used to demonstrate the ideas.

Week 8 – Linear Regression

Linear regression is a supervised learning method for predicting a numerical target. A simple example is predicting an exam score from hours studied.

TermMeaning
LinearRegression()Create a linear regression model.
.fit(X_train, y_train)Train/fit the model.
.predict(X_test)Generate predictions for given features.
PredictionModel's estimated numerical output.
Residual/errorActual value minus predicted value.
MAEMean absolute error; average absolute size of prediction errors.

Simple regression example

import pandas as pd
from sklearn.linear_model import LinearRegression

X = pd.DataFrame({"Hours": [1, 2, 3, 4, 5]})
y = [50, 60, 70, 80, 90]

model = LinearRegression()
model.fit(X, y)
print(model.predict(pd.DataFrame({"Hours": [6]})))

Expected output: approximately [100.]. The model learns a relationship of about 10 score points per additional study hour in this idealized example.

A straight-line prediction is often written as predicted y = intercept + slope × x. The slope describes how much the prediction changes when the feature increases by one unit.

Evaluating predictions

from sklearn.metrics import mean_absolute_error
actual = [80, 90, 70]
predicted = [78, 85, 75]
print(mean_absolute_error(actual, predicted))

Output: 4.0, because the absolute errors are 2, 5, and 5; their average is 4. Smaller MAE generally means closer numerical predictions on the same evaluation task.

Remember: Linear regression predicts numbers, not Yes/No classes. A model may perform well on training data yet poorly on new data.

Week 9 – Logistic Regression and Classification

Despite its name, logistic regression is commonly used for classification. In binary classification, it estimates a probability for a class, then uses a decision threshold to assign a label.

ConceptKnow this
Binary classificationChoose between two classes, such as Pass/Fail.
Predicted probabilityEstimated likelihood of a class, from 0 to 1.
ThresholdCutoff used to convert a probability into a class prediction, often 0.5.
LogisticRegression()Creates a classification model.
.predict()Returns predicted class labels.
.predict_proba()Returns estimated probabilities for each class.
AccuracyCorrect predictions divided by total predictions.

Classification example

import pandas as pd
from sklearn.linear_model import LogisticRegression

X = pd.DataFrame({"Hours": [1, 2, 3, 4, 5, 6, 7, 8]})
y = [0, 0, 0, 0, 1, 1, 1, 1]  # 0 = Fail, 1 = Pass

model = LogisticRegression()
model.fit(X, y)
print(model.predict(pd.DataFrame({"Hours": [2, 7]})))
print(model.predict_proba(pd.DataFrame({"Hours": [2, 7]})))

Expected class predictions: [0 1] (Fail for 2 hours, Pass for 7 hours). The probability output contains two values per student: one for class 0 and one for class 1. Probabilities depend on the fitted model.

Accuracy and confusion-matrix vocabulary

from sklearn.metrics import accuracy_score
actual = [1, 0, 1, 1, 0]
predicted = [1, 0, 0, 1, 0]
print(accuracy_score(actual, predicted))

Output: 0.8, or 80% accuracy, because four of five predictions are correct.

TermMeaning
True positive (TP)Predicted positive, actually positive.
True negative (TN)Predicted negative, actually negative.
False positive (FP)Predicted positive, actually negative.
False negative (FN)Predicted negative, actually positive.
PrecisionAmong predicted positives, the fraction actually positive.
RecallAmong actual positives, the fraction correctly found.

For example, if a system flags a passing student as “Fail,” and “Fail” is defined as the positive class, that is a false positive. Always identify which class is positive before interpreting a confusion matrix.
