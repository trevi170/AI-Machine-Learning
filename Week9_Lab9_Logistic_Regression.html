Part 4: Split Training and Testing Data

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42, stratify=y
)
print("Training rows:", len(X_train))
print("Testing rows:", len(X_test))

Expected: Training rows: 12; Testing rows: 4. The stratify=y setting attempts to preserve class proportions in both groups.

Part 5: Train a Logistic Regression Model

from sklearn.linear_model import LogisticRegression

model = LogisticRegression(random_state=42)
model.fit(X_train, y_train)
print("Model trained successfully")

Expected: Model trained successfully. fit() teaches the model from training examples.

Part 7: Calculate Accuracy

from sklearn.metrics import accuracy_score, confusion_matrix

accuracy = accuracy_score(y_test, predictions)
print("Accuracy:", round(accuracy, 2))
print("Confusion matrix:")
print(confusion_matrix(y_test, predictions, labels=[0, 1]))

Accuracy is the fraction of test predictions that match the actual labels. The confusion matrix counts correct and incorrect predictions by class.

Part 8: Predict New Students

new_students = pd.DataFrame({"Hours_Studied": [2, 5, 8]})
new_students["Predicted_Pass"] = model.predict(new_students[["Hours_Studied"]])
new_students["Probability_of_Pass"] = model.predict_proba(
    new_students[["Hours_Studied"]]
)[:, 1].round(3)
print(new_students)

The probability is the model's estimated probability for class 1 (Pass), not a guarantee of an outcome.
