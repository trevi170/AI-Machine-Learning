Lab Overview

This lab introduces you to Google Colab and basic Python programming. You will create your first notebook, run Python code, display text and numbers, perform simple calculations, create variables, and begin thinking about how Python is used in machine learning.

Learning Objectives
  • Open and navigate Google Colab.
  • Create and rename a notebook.
  • Use code cells to run Python instructions.
  • Use print() to display text and numbers.
  • Perform basic arithmetic operations.
  • Create simple Python variables.
  • Explain how Python will be used later in machine learning.

Part 1 – Open Google Colab

  1. Open a web browser such as Google Chrome, Microsoft Edge, Safari, or Firefox.
  2. Go to https://colab.research.google.com.
  3. Sign in with your Google account if prompted.
  4. Select File → New notebook.
  5. Rename your notebook using this format:
LastName_FirstName_Week1

Example:

Garcia_Maria_Week1
Important: Google Colab saves your notebook to Google Drive. Make sure you are signed in to the correct account before beginning.

Part 11 – Independent Challenge

Create three variables:

  • Your favorite number
  • Your birth year
  • The current year

Then use Python to calculate an approximate age.

Example structure:

favorite_number = 7
birth_year = 2007
current_year = 2026

age = current_year - birth_year

print("Favorite Number:", favorite_number)
print("Approximate Age:", age)
Your calculated age may be one year different depending on whether your birthday has already occurred this year. That is okay for this activity.
