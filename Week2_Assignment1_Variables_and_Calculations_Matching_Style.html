Assignment Overview

In this assignment, you will use the Python skills from Week 2 to create a simple Student Information and Grade Calculator. Your program will collect information from a user, store the information in variables, perform calculations, and display the results.

Learning Objectives
  • Create and use variables.
  • Collect information with input().
  • Convert user input into numerical values.
  • Perform arithmetic calculations.
  • Display organized output.
  • Explain how student data could be used in a future machine-learning project.

Part 2 – Create the Student Grade Calculator

Your program must:

  1. Ask the user to enter the student's name.
  2. Ask the user to enter three exam scores.
  3. Convert each exam score to an integer or float.
  4. Calculate the total of the three exam scores.
  5. Calculate the average.
  6. Display the student's name, total, and average.

Part 3 – Example Program Structure

You may use the following structure as a guide:

name = input("Enter student name: ")

score1 = float(input("Enter Exam 1 score: "))
score2 = float(input("Enter Exam 2 score: "))
score3 = float(input("Enter Exam 3 score: "))

total = score1 + score2 + score3
average = total / 3

print("Student:", name)
print("Total:", total)
print("Average:", average)
